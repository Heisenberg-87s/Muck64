# Muck 64 - Alpha release ver 0.0.1
> **Super Mario 64 in Muck (Powered by libsm64)**

---

## 📦 1. สิ่งที่จำเป็นต้องมีก่อนติดตั้ง (Requirements)
1. **ตัวเกม Muck** (Steam เวอร์ชั่นล่าสุด)
2. **BepInEx 5 (64-bit)** สำหรับ Unity Mono *(แนะนำ BepInEx_x64_5.4.x สามารถดาวน์โหลดได้จาก GitHub BepInEx)*
3. **ไฟล์ ROM "Super Mario 64" เวอร์ชั่น USA (NTSC-U)**:
   - ต้องตั้งชื่อไฟล์ว่า `baserom.us.z64` หรือ `sm64.z64`
   - *คำเตือน: ตามกฎหมายลิขสิทธิ์ของ Nintendo ตัว Mod จะไม่แถมไฟล์ ROM มาให้ ผู้เล่นต้องจัดหาไฟล์ ROM จากตลับแท้ของตนเอง*

---

## 🛠️ 2. วิธีการติดตั้ง (Installation Steps)

1. **เปิดโฟลเดอร์ของเกม Muck**:
   - ใน Steam: คลิกขวาที่เกม Muck -> `Manage` -> `Browse local files`
2. **ติดตั้ง BepInEx (ถ้ายังไม่มี)**:
   - แตกไฟล์ `BepInEx_x64` ลงในโฟลเดอร์เกม Muck (โฟลเดอร์เดียวกับ `Muck.exe`)
3. **คัดลอกไฟล์ Mod ลงเกม**:
   - นำโฟลเดอร์ `BepInEx` จากในโฟลเดอร์ Mod นี้ ไปวางทับในโฟลเดอร์เกม Muck *(จะมี `MuckMario.dll` และ `sm64.dll` อยู่ใน `BepInEx\plugins\`)*
   - นำไฟล์ `sm64.dll` ไปวางไว้ที่โฟลเดอร์หลักข้างๆ `Muck.exe` ด้วย
4. **วางไฟล์ ROM**:
   - นำไฟล์ ROM ของคุณที่ชื่อ `baserom.us.z64` หรือ `sm64.z64` ไปวางไว้ในโฟลเดอร์หลักของเกม Muck (ข้างๆ `Muck.exe`) หรือใน `BepInEx\plugins\`
5. **เข้าเล่นเกม**:
   - เข้าเกม Muck สร้างห้องเล่น แล้วกดปุ่ม **`F1`** เพื่อแปลงร่างเป็น Mario 64 ได้ทันที!

## 🎮 3. ปุ่มควบคุมและการเล่น (Controls & Hotkeys)

### ปุ่มฟังก์ชั่นพิเศษ
| ปุ่ม | การทำงาน |
| :--- | :--- |
| **`F1`** | สลับเข้า / ออก โหมด Mario 64 (สลับกลับเป็น Muck บุคคลที่หนึ่งได้ตลอดเวลา) |
| **`F2`** | สแกนภูมิประเทศใหม่ (Reload Terrain Collision) ใช้เมื่อตัดไม้ สร้างบ้าน หรือเดินตกแมพ |
| **`F3`** | เปิด / ปิด แถบแสดงข้อความช่วยเหลือบนหน้าจอ (HUD) |
| **`F4`** | เปิด / ปิด ระบบ BLJ Turbo Jump (กด Space ค้างเพื่อกระโดดรัวระดับเฟรมเป๊ะ) |
| **`F5`** | สลับระดับความเร็ว BLJ GameShark Cheat (`Off` -> `Simple` -> `Medium` -> `FasterOMG`) |
| **`F6`** | เปิด / ปิด หน้าต่าง **Mario Color Customizer** (ปรับแต่งสี RGB อิสระ 6 ส่วน + Sync สีให้เพื่อนเห็น) |

### การเคลื่อนไหวของ Mario 64
| ปุ่ม | การทำงาน |
| :--- | :--- |
| **`W, A, S, D`** | เคลื่อนที่ (3D Analog Movement) |
| **`Space`** | กระโดด / กระโดด 3 จังหวะ (Triple Jump) / กระโดดเด้งกำแพง (Wall Kick) |
| **`E`** | ต่อย (Punch) / พุ่งไดร์ฟ (Dive) / สไลด์เตะ (Slide Kick) — ต่อยต้นไม้ หิน หีบสมบัติ และมอนสเตอร์ได้ |
| **`R`** หรือ **`E`** | เปิดหีบสมบัติ (Chest) / ใช้งานโต๊ะคราฟต์ / เก็บไอเทม |
| **`Left Ctrl`** หรือ **`C`** | ก้มตัว (Crouch)<br>• กดกลางอากาศ = ทิ้งดิ่งพื้น (Ground Pound) สร้างความเสียหาย 120 AOE<br>• วิ่งแล้วกด Ctrl + Space = กระโดดยาว (Long Jump)<br>• ถอยหลังแล้วกด Ctrl + Space รัวๆ = ท่า BLJ ในตำนาน! |
| **`Left Shift`** | วิ่งเร็วขึ้น (Sprint) |
| **หมุนเมาส์** | หมุนมุมกล้องอิสระ 360 องศา |
| **ลูกกลิ้งเมาส์ (Scroll Wheel)** | ซูมกล้อง เข้า-ออก |

## ✨ 4. ฟีเจอร์เด่นในเวอร์ชันนี้
- **Real SM64 Physics**: ฟิสิกส์ Mario 64 แท้ 100% จำลองจากต้นฉบับ N64 ผ่าน libsm64
- **Multiplayer Synchronized**: ซิงค์ท่าทางอนิเมชั่น, การกระโดด, ทิศทางหันหน้า และตำแหน่งในโหมดผู้เล่นหลายคนตรงกัน
- **Color Customizer (F6)**: ปรับแต่งสีเอี้ยม, เสื้อหมวก, สีผิว, ผม-ตา, ถุงมือ, รองเท้า ด้วย RGB Slider พร้อมบันทึกและแชร์ให้เพื่อนเห็น
- **Auto Item Pickup**: เก็บไอเทมบนพื้น พาวเวอร์อัป กิ่งไม้ และก้อนหินเข้ากระเป๋าได้ตามปกติ
- **Independent Hitbox**: ระบบ Hitbox แยกอิสระ เดินไม่ติดขัด ไม่ชนเบียดกับตัวละครเดิม
- **Smooth Camera**: ระบบกล้อง Smooth 60+ FPS แก้ปัญหาการสั่นเรียบร้อย
- **Flawless First-Person Restore**: สลับกลับร่าง Muck First-Person ได้อย่างสมบูรณ์แบบ มุมกล้องไม่เอียง
