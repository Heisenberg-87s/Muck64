================================================================================
  Muck 64 - Alpha release ver 0.0.1
  Super Mario 64 in Muck (Powered by libsm64)
================================================================================

[ 1. สิ่งที่จำเป็นต้องมีก่อนติดตั้ง (Requirements) ]
--------------------------------------------------------------------------------
1. ตัวเกม Muck (Steam เวอร์ชั่นล่าสุด)
2. BepInEx 5 (64-bit) สำหรับ Unity Mono 
   (แนะนำ BepInEx_x64_5.4.x สามารถดาวน์โหลดได้ฟรีจาก GitHub BepInEx)
3. ไฟล์ ROM "Super Mario 64" เวอร์ชั่น USA (NTSC-U):
   - ต้องตั้งชื่อไฟล์ว่า "baserom.us.z64" หรือ "sm64.z64"
   * คำเตือน: ตามกฎหมายลิขสิทธิ์ของ Nintendo ตัว Mod จะไม่แถมไฟล์ ROM มาให้ 
     ผู้เล่นต้องจัดหาไฟล์ ROM จากตลับแท้ของตนเอง


[ 2. วิธีการติดตั้ง (Installation Steps) ]
--------------------------------------------------------------------------------
ขั้นตอนที่ 1: 
  เปิดโฟลเดอร์ของเกม Muck
  (ใน Steam ให้คลิกขวาที่เกม Muck -> Manage -> Browse local files)

ขั้นตอนที่ 2:
  หากยังไม่เคยลง BepInEx ให้แตกไฟล์ BepInEx x64 ลงในโฟลเดอร์เกม Muck ก่อน
  (จะมีโฟลเดอร์ BepInEx, ไฟล์ winhttp.dll, doorstop_config.ini อยู่ข้าง Muck.exe)

ขั้นตอนที่ 3:
  คัดลอกไฟล์จากตัว Mod นี้ไปวางในโฟลเดอร์เกม Muck:
  - นำโฟลเดอร์ "BepInEx" ไปวางทับในโฟลเดอร์เกม Muck
    (ข้างในจะมี MuckMario.dll และ sm64.dll อยู่ใน BepInEx\plugins\)
  - นำไฟล์ "sm64.dll" ไปวางไว้ที่โฟลเดอร์หลักข้างๆ Muck.exe ด้วย

ขั้นตอนที่ 4:
  นำไฟล์ ROM ของคุณที่ชื่อ "baserom.us.z64" หรือ "sm64.z64"
  ไปวางไว้ที่โฟลเดอร์เกม Muck (ข้างๆ Muck.exe) หรือใน BepInEx\plugins\

ขั้นตอนที่ 5:
  เข้าเกม Muck กดเริ่มเกม สร้างโลก แล้วกดปุ่ม [ F1 ] เพื่อแปลงร่างเป็น Mario 64 ได้เลย!


[ 3. ปุ่มควบคุมและการเล่น (Controls & Hotkeys) ]
--------------------------------------------------------------------------------
[ปุ่มฟังก์ชั่นพิเศษ]
  - F1 : สลับเข้า / ออก โหมด Mario 64 (สลับกลับเป็น Muck บุคคลที่หนึ่งได้ตลอดเวลา)
  - F2 : สแกนภูมิประเทศใหม่ (Reload Terrain Collision) 
         (ใช้เมื่อสร้างบ้านใหม่ ตัดต้นไม้ หรือเดินตกแมพ)
  - F3 : เปิด / ปิด แถบแสดงข้อความช่วยเหลือบนหน้าจอ (HUD)
  - F4 : เปิด / ปิด ระบบ BLJ Turbo Jump (กด Spacebar ค้างเพื่อกระโดดรัวระดับเฟรมเป๊ะ)
  - F5 : สลับระดับความเร็ว BLJ GameShark Cheat:
         [ Off -> Simple -> Medium -> FasterOMG (วาปข้ามมิติ) ]
  - F6 : เปิด / ปิด หน้าต่าง Mario Color Customizer (ปรับแต่งสี 6 ส่วนด้วย RGB Slider และแชร์ให้เพื่อนเห็น)

[การเคลื่อนไหวของ Mario 64]
  - W, A, S, D : เคลื่อนที่ (3D Analog Movement)
  - Space : กระโดด / กระโดด 3 จังหวะ (Triple Jump) / กระโดดเด้งกำแพง (Wall Kick)
  - E : ต่อย (Punch) / พุ่งไดร์ฟ (Dive) / สไลด์เตะ (Slide Kick) 
        * ใช้ต่อยทำลายต้นไม้, หิน, และโจมตีมอนสเตอร์ได้
  - R หรือ E : เปิดหีบสมบัติ (Chest) / ใช้งานโต๊ะคราฟต์ / เก็บไอเทม
  - Left Ctrl หรือ C : ก้มตัว (Crouch)
        * กดกลางอากาศ = ทิ้งดิ่งพื้น (Ground Pound) สร้างความเสียหาย 120 AOE
        * วิ่งแล้วกด Ctrl + Space = กระโดดยาว (Long Jump)
        * ถอยหลังแล้วกด Ctrl + Space รัวๆ = ท่า BLJ ในตำนาน!
  - Left Shift : วิ่งเร็วขึ้น (Sprint)
  - หมุนเมาส์ : หมุนมุมกล้องอิสระ 360 องศา
  - ลูกกลิ้งเมาส์ (Scroll Wheel) : ซูมกล้อง เข้า-ออก 


[ 4. ฟีเจอร์เด่นในเวอร์ชันนี้ ]
--------------------------------------------------------------------------------
- ฟิสิกส์ Mario 64 แท้ 100% จำลองจากต้นฉบับ N64 ผ่าน libsm64
- รองรับโหมดผู้เล่นหลายคน (Multiplayer) ซิงค์อนิเมชั่น ท่าทาง ทิศทาง และตำแหน่งตรงกันสมบูรณ์
- ระบบปรับแต่งสี Mario Color Customizer (F6) พร้อมปุ่มบันทึกและซิงค์สีให้เพื่อนร่วมห้องเห็นโมเดลของเรา
- ระบบดูดไอเทมที่ดรอปบนพื้น พาวเวอร์อัป กิ่งไม้ และหินเข้ากระเป๋าอัตโนมัติ
- ตีมอนสเตอร์, ตีต้นไม้, ทุบหิน, เปิดหีบสมบัติได้
- ระบบ Hitbox แยกอิสระ เดินไม่ติดขัด ไม่ชนเบียดกับตัวละครเดิม
- ระบบกล้อง Smooth Camera 60+ FPS แก้ปัญหาการสั่นเรียบร้อย
- สลับกลับร่าง Muck First-Person ได้อย่างสมบูรณ์แบบ มุมกล้องไม่เอียง
